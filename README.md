# ПрофНавигатор СПО — Web App

Профориентационный тест для школьников города Каменска-Уральского. Рекомендует специальности и колледжи на основе профиля интересов.

## Возможности

- 20-вопросный тест интересов с оценкой по 5-балльной шкале
- Анализ по 9 профессиональным профилям и 7 типам личности
- Таблица рекомендаций с процентом совпадения
- Режим психолога/администратора:
  - Просмотр и поиск по всем результатам
  - Статистика (профили, колледжи, типы личности)
  - Редактор колледжей и специальностей
  - Экспорт в CSV
- Данные хранятся локально в браузере (IndexedDB + localStorage)
- Поддержка светлой и тёмной темы

## Стек

- React 18 + Vite 5
- CSS Modules (без внешних UI-библиотек)
- IndexedDB для результатов, localStorage для справочника колледжей

```bash

```

```bash

```

Готовые файлы в папке `dist/`.

## Хостинг на GitHub Pages

### Автоматически (рекомендуется)

1. Создайте репозиторий на GitHub
2. Залейте код в ветку `main`
3. В настройках репозитория: **Settings → Pages → Source** выберите **GitHub Actions**
4. При каждом пуше в `main` сайт автоматически пересобирается и публикуется

Workflow файл: `.github/workflows/deploy.yml`

### Вручную

```bash
npm run build
# Загрузите содержимое папки dist/ в ветку gh-pages
```

## Добавление колледжей

1. Откройте приложение в браузере
2. На главной странице нажмите **«Режим психолога»**
3. Пароль: `kurt_admin`
4. Перейдите на вкладку **«Колледжи»**
5. Добавьте колледжи и специальности, укажите теги и профили
6. Нажмите **«Сохранить всё»**

Данные сохраняются в localStorage браузера. Для переноса на другой компьютер экспортируйте через консоль браузера:
```js
localStorage.getItem('profnav_colleges')
```

## Структура проекта

```
src/
  lib/
    data.js          — вопросы, теги, профили, справочник колледжей
    recommender.js   — алгоритм рекомендаций
    db.js            — IndexedDB для результатов
  pages/
    IntroPage        — главная страница
    TestPage         — тест (20 вопросов)
    ResultPage       — результаты и рекомендации
    AdminPage        — панель психолога/администратора
  App.jsx
  main.jsx
  index.css          — CSS-переменные и базовые стили
```
